About this computer

This is a simulated computer UI built with HTML, CSS, and JavaScript. The mini browser uses an iframe to load pages.

Back/Forward uses a local history stack. Some websites use headers like X-Frame-Options or Content-Security-Policy to prevent embedding, so they may not display here.

Try the sidebar bookmarks, add notes, and switch tabs. You can tweak the theme in the CSS variables at the top.
